# 隐私说明

本扩展面向本地开发调试使用。按当前实现：

- 不包含分析 SDK、远程代码或向项目维护者运营的服务器上传数据的逻辑；
- 由于使用 `<all_urls>`，内容脚本可能在匹配的网页中读取元素和 Console 输出，用于用户主动发起的元素选择和日志复制；
- Console 输出会按标签页暂存在浏览器扩展存储中，标签页关闭时清理；
- 元素上下文和 Console 输出只会在用户点击对应按钮后复制到本机剪贴板。

网页本身可能包含密码、令牌或个人信息。请在复制前确认内容适合放入剪贴板，也不要在公开 Issue 中粘贴真实敏感数据。若将本项目改造成联网产品，请同步更新权限、代码和本说明。
